# i4T Maintenance – Work Orders and Calendar Prototype V6

Open `index.html` for a standalone local preview or deploy these files at the root of a static Vercel project.

## Changes in V6
- Sidebar: **Work Orders** with **All** and **Future & Recurring** child links; **Calendar** remains separate.
- Future & Recurring table now uses the existing Recurring WO ID, Task ID, Creation Date, Recurrence Frequency, Description, Strata Plan Name, Strata Plan Number, Issued By, Previous Occurrence, Next Occurrence, Final Occurrence and Actions columns. No Schedule Status column/filter.
- Standard **All Work Orders** screen included as a *read-only visual reference* from the supplied screenshot; it does not reproduce live standard WO actions or alter existing WO functionality.
- Existing Future & Recurring View/Edit/Pause/Resume/Cancel and Calendar interactions preserved. One-off configurations do not offer Pause/Resume; cancelled rows show only View.

All records are illustrative. Demo notifications, compliance and scheduling are simulated and do not connect to i4T Business.
